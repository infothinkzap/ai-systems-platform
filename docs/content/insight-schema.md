# Insight Schema (Think Section)

Defines the structure for thought-leadership and philosophy articles.

## 1. Frontmatter (MDX)
```yaml
id: "insight:systems_over_prompts"
title: "Systems Over Prompts"
author: "person:adarsh"
date: "2026-08-14"
```

## 2. Dynamic Graph Injection
- **Related Philosophy**: Linked to `phil:systems_thinking`
- **Related Systems**: Links to any Systems that demonstrate this thought process.

## 3. Editorial Body (Human Written)
Long-form markdown content.
- Must not be generic AI blogging.
- Must focus on engineering, systems architecture, human workflows, or first-principles reasoning.
- Should generously use Mermaid graph visualizations to explain abstract concepts.
