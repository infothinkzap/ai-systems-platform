# Service Page Schema

Defines the structure for Systems Mode consulting/engineering pages (e.g., `/services/system-design`).

## 1. Frontmatter (MDX)
```yaml
id: "service:system_design"
title: "AI System Design"
tagline: "Architecting intelligence for unique operational friction."
```

## 2. Dynamic Graph Injection
- **Journey Step Addressed**: `SERVICE_ADDRESSES` → `journey:system_design`
- **Maturity**: Service status (e.g., commercial).

## 3. Editorial Body (Human Written)

### The Client Context
When should a business engage this service? (e.g., "You have complex workflows that off-the-shelf SaaS cannot handle.")

### The Methodology
Step-by-step breakdown of how Terrawave executes this service, referencing the `method:` entities (Understand, Deconstruct, Design).

### Deliverables
What exactly does the client receive? (e.g., An Architecture Blueprint, a Prototype, a Production System).

### Next Step (CTA)
"Book an AI Opportunity Discovery session."
