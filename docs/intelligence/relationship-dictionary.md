# Relationship Dictionary

This dictionary defines the approved semantic relationship verbs used in the Terrawave Master Knowledge Graph.

To prevent graph bloat and maintain clarity, use only these relationships when extending the `terrawave-graph.yaml` file. Each relationship is directed (`Source` → `Relationship` → `Target`).

## Structural & Organizational

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `FOUNDED_BY` | Denotes creation and ownership of an organization or entity by a person. | Terrawave `FOUNDED_BY` Adarsh Singh Pawar |
| `BELONGS_TO` | Denotes that a concept, system, or asset is owned by or nested within a larger entity or domain. | AI CFO `BELONGS_TO` Business Intelligence |
| `SEPARATE_FROM` | Explicitly maps a brand boundary or firewall between two concepts that must not be merged. | Terrawave `SEPARATE_FROM` Randomly Systematic |
| `COMPRISES` / `HAS_PART` | A whole-to-part relationship (e.g., a process has steps, an architecture has layers). | Terrawave Method `COMPRISES` Step 1: Identify Problem |
| `OPERATES_BY` | Indicates the core philosophy or principles guiding an entity. | Terrawave `OPERATES_BY` Problem First |

## Personas & User Journeys

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `HAS_PROBLEM` | Connects a Persona to a specific friction point or challenge. | CFO `HAS_PROBLEM` Financial Complexity |
| `USES_SYSTEM` | Connects a Persona to the Product or System they interact with. | Accounting Team `USES_SYSTEM` CA Automation |
| `PERFORMS_WORKFLOW` | Connects a Persona to a specific operational process. | Sales Team `PERFORMS_WORKFLOW` Lead Follow-up |
| `DESIRES_OUTCOME` | Connects a Persona to their qualitative goal. | Student `DESIRES_OUTCOME` Personalized Exam Preparation |
| `PROGRESSES_TO` | Indicates a sequential step in a journey or iterative method. | Prototype `PROGRESSES_TO` Implementation |
| `EXPERIENCES` | Indicates that a workflow directly suffers from a specific problem. | Invoice Processing `EXPERIENCES` Document Processing Burden |

## Offerings: Products & Services

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `PRODUCT_SOLVES` | A packaged product provides the solution to a specific problem. | AI CFO `PRODUCT_SOLVES` Financial Complexity |
| `SUPPORTS_WORKFLOW` | Indicates a system enables or automates a specific workflow. | CA Automation `SUPPORTS_WORKFLOW` Invoice Processing |
| `SERVICE_ADDRESSES` | A consulting/systems service targets a specific domain or friction. | AI Workflow Analysis `SERVICE_ADDRESSES` Undefined Operational Friction |
| `SERVICE_USES` | A service that relies on a specific capability. | AI System Design `SERVICE_USES` Workflow Orchestration |
| `SERVICE_SUPPORTS` | A service that aids in the deployment or use of a product or workflow. | AI Integration `SERVICE_SUPPORTS` CA Automation |
| `SERVICE_CUSTOMIZES` | A service that adapts a baseline system for a unique client. | Custom Development `SERVICE_CUSTOMIZES` Intelligence Layer |
| `SERVICE_INTEGRATES` | A service connecting disparate systems. | AI Integration `SERVICE_INTEGRATES` External APIs |

## Functional & System Dynamics

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `USES` | A system relies on a specific capability or technology to function. | CA Automation `USES` Document Intelligence |
| `ENABLES` | A technology, capability, or system unlocks a new outcome or capability. | Knowledge Graphs `ENABLES` Contextual Reasoning |
| `PRODUCES` | The direct output or artifact generated by a system or process. | Lead Intelligence `PRODUCES` Structured Intent Data |
| `GENERATES` | Similar to produces, but often used for content, revenue, or abstract value. | AI Integration `GENERATES` Practical Real-World Outcomes |
| `CONSUMES` | Identifies the Data Primitives required by a system or capability. | Intelligence Layer `CONSUMES` Invoices |
| `OPERATES_ON` | Defines the specific medium or domain a system manipulates. | ExamOS `OPERATES_ON` Syllabus Intelligence |

## Capability & Data Processing

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `EXTRACTS_FROM` | A capability pulls structured data from an unstructured/semi-structured primitive. | Document Intelligence `EXTRACTS_FROM` Invoice |
| `TRANSFORMS` | A capability changes the structure or format of a primitive. | Conversation Intelligence `TRANSFORMS` WhatsApp Chat |
| `PROCESSES` | A general relationship indicating data flows through a capability. | Adaptive Planning `PROCESSES` Performance Data |
| `ENRICHES` | Adding metadata or context to a primitive. | Graph Intelligence `ENRICHES` Transactions |
| `VALIDATES` | Checking correctness against rules. | Deterministic Layer `VALIDATES` Extracted GST |
| `DERIVES` | Generating new conclusions from existing data. | Intent Detection `DERIVES` Lead Qualification |
| `INFORMS` | A processed capability outputs context to a decision node. | Financial Reasoning `INFORMS` Decision Support |
| `CAPABILITY_BELONGS_TO_GROUP` | A capability belongs to a larger cognitive category (Understand/Reason/Execute). | Intent Detection `CAPABILITY_BELONGS_TO_GROUP` REASON |

## Data Provenance

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `ORIGINATES_FROM` | The root source of a data primitive. | Transactions `ORIGINATES_FROM` ERP |
| `IMPORTED_FROM` | Data brought in manually or via bulk processes. | Vendor Data `IMPORTED_FROM` CSV |
| `RECEIVED_THROUGH` | The channel through which data streams. | Chat Message `RECEIVED_THROUGH` WhatsApp API |
| `SYNCHRONIZED_FROM` | An automated bidirectional or sync link. | Syllabus Data `SYNCHRONIZED_FROM` External Database |

## Metrics & Outcomes

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `MEASURED_BY` | Connects a qualitative outcome to a quantitative metric. | Reduced Manual Workload `MEASURED_BY` Hours Saved |
| `IMPROVES` | A feedback loop where a target becomes better, or a metric goes in a positive direction. | Better Decisions `IMPROVES` Revenue |
| `REDUCES` | A metric or problem goes in a negative direction (beneficial). | CA Automation `REDUCES` Error Rate |
| `INCREASES` | A metric goes in a positive direction. | Automation `INCREASES` Processing Speed |

## Dependencies & Lifecycle

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `DEPENDS_ON` | A critical necessity; a target must exist or succeed for the source to function. | Automated Execution `DEPENDS_ON` Deterministic Validation |
| `BUILT_BY` | Indicates the engineering or design origin of a product or system. | Terrawave Platform `BUILT_BY` Terrawave Engineering |
| `PRECEDES` | A chronological or sequential order (e.g., in a method or version evolution). | V1 Website `PRECEDES` V2 Interactive Graphs |
| `REQUIRES` | A prerequisite condition or input. | Human Approval `REQUIRES` Exception Escalation |

## Integration & Evaluation

| Relationship | Meaning | Example |
| :--- | :--- | :--- |
| `INTEGRATES_WITH` | Two distinct systems or APIs connect and communicate. | Action Layer `INTEGRATES_WITH` External APIs |
| `VALIDATES` | A system or step that checks the correctness of another system's output. | Deterministic Systems `VALIDATES` LLM Generation |
| `DEMONSTRATES` | Shows evidence, trust, or capability. | Case Studies `DEMONSTRATES` Technical Depth |
| `LEADS_TO` | A causal relationship describing eventual outcomes. | Better Financial Decisions `LEADS_TO` Long-Term Relationship |
